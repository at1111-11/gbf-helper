# 그랑블루 도우미 (Edge / Chrome 확장프로그램)

브라우저 오른쪽 패널(사이드 패널)에 띄워 쓰는 그랑블루 판타지 보조 도구입니다.
**게임 페이지에 접속하거나 게임 화면을 읽지 않습니다.** 사이트 접근 권한이 없고, 인터넷 요청도 하지 않습니다.

## 웹사이트로 쓰기 (설치 없음)
- 주소: https://at1111-11.github.io/gbf-helper/
- Edge 오른쪽 사이드바의 `+`(사이드바 사용자 지정)에서 위 주소를 추가하면 확장처럼 오른쪽에 붙여 쓸 수 있어요.
- 체크·메모는 각자 브라우저에만 저장됩니다 (서버로 보내지 않음, 다른 사람과 공유되지 않음).

## 확장으로 설치
1. 이 저장소를 내려받아 압축 풀기 (Code → Download ZIP)
1. Edge 주소창에 `edge://extensions` 입력
2. 왼쪽 아래 "개발자 모드" 켜기
3. "압축을 푼 확장 로드" → 이 폴더(`gbf-helper`) 선택
4. 툴바의 달 모양 아이콘을 누르면 오른쪽 패널이 열립니다 (퍼즐 아이콘에서 고정해 두면 편해요)

## 기능
### 월간교환
- 매월 리셋되는 골드문 / 반홍(하프 엘릭서) / 시드(소울 시드) 교환처를 게임 상점 그림과 함께 한 줄씩 정리
  - FP 교환, 펜던트, 카지노, 스카이립, 데일리 포인트, 트레저 교환(반홍은 총 수량, 시드는 종류 수를 칩 안 칸에 적고 Enter, !에 안내)
- 아이템 아이콘을 누르면 교환함(✓, 흐리게), 교환소 그림을 누르면 그 교환소 전체 체크
- 매월 1일 05:00(일본·한국 시간)에 체크가 자동으로 풀립니다
- [편집]: 수량 수정, 항목 숨기기, 항목·교환소 직접 추가
- 수량 출처: gbf.wiki (2026-11-25 확인). 상점·아이템 그림은 gbf.wiki에서 한 번 받아 `img/`에 넣어 두었습니다 (실행 중에는 아무 데도 접속하지 않음)

### 극성기 계산기
- 퀘스트·버프 / 파티 두 묶음의 드롭다운으로 극성기 드롭률 계산 (상자에서 극성기가 나올 확률 8% 고정)
- 상자 드롭률은 90헬~250헬 중 선택 (250헬 4.5%는 미확인 추정값)
- 극성기·상자 드롭률과 평균 주회수, 극성기 파편 획득·필요 개수를 표시
- 파티 칸은 고른 캐릭터·무기·소환석 그림을 함께 보여줌 (img/party/)
- 계산식은 liliel 님의 トレハン計算機(ver0.31)와 같습니다 (무작위 1,000개 조합으로 결과 일치 확인)

### 고전장
- EX+~250헬 체력·방어·공헌도·고기, 헬마다 테스트 몹 목표 HP(속성 배지로 전환), 시간당 공헌도 비교

### 레이드 탐색기
- 보스와 조건을 고르면 일본어·영어 공략 검색어를 만들어 복사하거나 유튜브·구글·X에서 검색 (도움 : ww99w)
- 보스 카드에 파상 공헌도, 파상·금상·빨상에서 나오는 모래시계·히히 확률 표시 (gbf.wiki 드롭표 기준)

### 패턴표
- 천원 / 루시제로 / 베르수시아: 세로 체력바를 따라 HP 순서로 패턴 정리, 옆에 체력 위치에 맞춘 내 행동 메모

## 테스트 (개발용)
Playwright가 있는 Node로 실행합니다.
- `node --test tests/core.test.cjs` — 리셋 시각, 체크리스트 합계, 드롭률 계산, 네트워크 미사용 확인
- `node tests/panel.cjs` — Edge에 확장을 올려 패널 화면을 직접 조작 (스크린샷: `tests/artifacts`)
- `node tools/make-icons.cjs` — tools/icon-source.webp로 아이콘 다시 만들기
